# 打板看板（题材梯队 + 分时 + 盘中/盘后/历史）设计

日期：2026-11-11
状态：草案，待维护者审阅（暂不动代码）
来源：维护者头脑风暴会话（Claude Code 代为整理）。下文区分**维护者已定**与**设计者决定（可改）**。
页面设计稿：[`2026-11-11-limit-up-board-mockup.html`](2026-11-11-limit-up-board-mockup.html)
（v6，静态示意，数据为虚构；浏览器直接打开）。

## 1. 意图

维护者打板时，在一只票即将封板的那几分钟里，需要一眼看到：

1. 同题材里**谁先封板**、各自**几连板**，判断这只票是龙头还是跟风；
2. 该题材的**梯度**（首板 / 2 板 / 3 板…是否完整）；
3. 全市场**连板梯队**（最高板、各层晋级情况），判断情绪高度和主线。

收盘后和之后任意交易日，同一个页面用于复盘。

主流工具（同花顺涨停聚焦、开盘啦/韭研涨停简图、开源 zt-ladder）都采用
"情绪栏 → 题材 × 高度矩阵 → 分时/时间轴"的结构，本设计沿用。差别在于：本看板
接入本仓库真值数据、遵守数据铁律、可审计盘中观测与盘后直取的差异。本看板是只读的
**辅助决策**页面。

## 2. 目标 / 非目标 / 反目标

**目标（维护者已定：盘中和盘后同等重要，一起上线）**
- **盘中实时**：快照 15 秒级的情绪栏、题材 × 连板高度矩阵、分时联动、题材家数曲线、
  封板时间轴。
- **当日盘后定版**：直取数据发布后，以直取值为准定版，并标出与盘中观测的差异。
- **历史日期**：任选交易日查看定版矩阵与分时；有盘中留存的日子可拖动时间回放。

**非目标**
- 不下单、不产生交易信号、不接入策略/Paper/Live 链路，不做主动推送提醒（维护者"主要盯着看"）。
- 不展示文字版"涨停原因"（`limit_list_ths.lu_desc` 需 8000 积分且盘后才有）。
- 不做龙头/中军/跟风等角色自动判定；**不新建预测模型**，晋级概率只展示已有 AI 涨停观察
  （影子榜单，#212）的结果（§5.5）。
- 不改 Windows 行情网关的频率或逻辑（维护者已定：15 秒够用）。

**反目标（即使能跑也算失败）**
- 任何反推、填充、默认值：连板数、封单额、封板时间拿不到就显示"未知"，不补值。
- 从名称、价格档位推 ST / 退市整理期 / 涨停价。
- 用当前概念成分回填历史日期的题材归属。
- 看板组件影响交易核心、行情网关或 Redis 现有键。
- 盘中派生与盘后直取不一致时静默不报。

## 3. 维护者已定的决定

| 项 | 决定 |
|---|---|
| 使用场景 | 盘中实时 + 当日盘后定版 + 历史日期复盘，**一起上线** |
| 板块口径 | 同花顺概念（Tushare `ths_index` / `ths_member`） |
| 题材归列 | 每只票**只放一列**：归入其所属概念中**当日涨停家数最多**者 |
| 涨停家数口径 | 截至当前时刻**当日封过板**的家数（含后来炸板的），只增不减；ST 计入，北交所不计入 |
| 泛概念 | 成分股 **> 300 只**的概念不参与归列 |
| 时间精度 | 15 秒快照级，不动网关 |
| 留存 | 每日存档，可按日期回放；临时全量文件例行删除的授权见 §6 |

## 4. 数据来源与派生口径

### 4.1 输入

| 输入 | 来源 | 时点 | 现状 |
|---|---|---|---|
| 全市场实时快照 | Redis `state:quote_realtime_latest`（`QuoteSnapshot`，Windows 网关 15s 写入，经隧道读取） | 盘中 | 已有 |
| 当日涨跌停价 | Redis `price_limits:YYYYMMDD`（盘前发布的 Tushare `stk_limit`） | 盘前 | 已有 |
| 连板数 / 首封 / 开板 / 封单 | warehouse `limit_list_daily`（Tushare `limit_list_d`：`limit_times`、`first_time`、`open_times`、`fd_amount`；自 2020 年起，**不含 ST**） | T 日 17:00 后 | 已有 |
| ST 涨停与 ST 身份 | warehouse `daily_flags.is_limit_up` / `is_st` | 盘后 | 已有 |
| 历史分时 | daily-archive 归档的 QMT 全市场 1 分钟线（canonical `bar_minute_1m`） | 每晚 | 已有；首根成交量为 0 问题见 D-23 |
| 同花顺概念及成分 | Tushare `ths_index`（概念类）+ `ths_member` | 盘前拉取 | **未接入，需探针** |

### 4.2 P0 探针（前置门禁）

1. `scripts/probe_ths_concepts.py`：实测当前账号能否调用 `ths_index`、`ths_member`；记录
   返回列、概念数量、成分数分布（>300 的有哪些）、`ths_member` 是否带生效/剔除日期、
   更新时点。结论落盘 `docs/reference/ths-concept-probe.md`。
   **不可调用则题材维度阻塞，回到维护者决定**（不得改用东财等其他口径替代）。
2. 盘口探针：确认 QMT `get_full_tick` 的 `bidVol`/`askVol` 单位（股或手），以及"字段缺失"
   与"真实为 0"能否区分。结论入测试。

### 4.3 派生口径（只允许直取或纯派生）

- **封板（盘中）**：价格等于直取涨停价**且卖一量确认为 0**。现有 `build_market_overview`
  在盘口量缺失时 `ask1_volume` 默认 0、退化为价格口径（`src/qsys/paper/quotes.py`），与
  本看板"不用默认值"冲突。**设计者决定**：本看板对盘口量缺失的到价票显示"到价·封板未知"，
  不计入封板、晋级、首封；`/market` 现有口径是否同步修正另开 Issue。无直取涨停价的标的
  不判封板，计入"缺涨停价"。
- **首次封板时刻（盘中）**：当日首次观测到封板的快照的**行情时间**（`MarketQuote.at`），
  标注"≈"。快照缺口内的封板不插值。
- **开板次数（盘中）**：观测序列中"封 → 未封"的次数，仅为观测值。
- **当日连板高度**：今日封板时 `高度 = 昨日连板数 + 1`；昨日未涨停为首板。非 ST 的昨日连板数
  取 `limit_list_daily.limit_times`；ST 用 `daily_flags.is_limit_up` 按交易日连续计数，序列中
  任一日缺行则为**未知**。昨日数据未入库（如 `limit_list_d` 迟发）时全体"高度未知"，不回退。
- **封单额**：盘中 `买一量 × 涨停价`（单位按探针结论换算，未确认前不展示）；盘后定版取
  `limit_list_d.fd_amount` 直取值。
- **晋级**：`昨日 N 板家数 → 今日其中封板家数`。
- **题材归列**：对每只"进入看板"的票，取其所属概念中成分 ≤ 300 的子集，选当日涨停家数
  （§3 口径）最多者；并列按概念代码升序；全部被排除归"其他"。
- **盘后对账**：`limit_list_d` 入库后，核对盘中派生的连板高度、首封时间（容许一个快照间隔）、
  开板次数；差异写入当日记录并在页面标出，不改写盘中原始观测。

## 5. 组成部分

### 5.1 盘中采集器（新 Linux 组件，暂名 `limit-up-board`）
- 盘中每 15 秒只读 Redis 最新快照，按 `published_at` 去重；超过 45 秒未更新（与 `/market`
  一致）记为缺口，不补点。
- 只读 Redis，不写任何现有键；只写本组件专属状态目录。Web 以只读方式读取（参照影子榜单：
  非 WAL 或经验证的只读方案，见 #529）。
- 维护盘中派生状态：入选票、封板/开板事件、首封、题材归列与改列事件、情绪栏聚合。

### 5.2 盘前概念快照
- 每个交易日盘前拉取 `ths_index` / `ths_member`，保存当日"股票 → 概念 / 概念 → 成分数"
  快照，带拉取时间与源记录指纹；当日内不变，**按日留存**，供历史回放使用。
- 拉取失败：当日题材维度不可用，矩阵退化为单列"全部"并明示原因。

### 5.3 Web 页面（布局见设计稿）
- 路由 `/market/limit-up-board`，作为"行情"子导航的新标签"打板看板"（位于"行情总览"与
  "涨停观察"之间）。只读 API `/api/market/limit-up-board?day=YYYY-MM-DD&at=HH:MM:SS`。
- 风格：复用 `base.html` 的顶栏、子导航、`page-head`、`metric-grid`、`panel`、`tabs`、`pill`
  和颜色变量，不引入新主题。颜色按 A 股惯例**涨红跌绿**（见 §5.6）。
- 页面自上而下：
  1. 标题区：交易日选择器 + 状态胶囊（实时 / 直取定版 + 对账差异数 / 无盘中留存）。
  2. 标签页：**盘中实时 / 盘后定版 / 历史日期**；盘后定版与有留存的历史日显示**盘中回放**
     滑杆，拖动后矩阵、情绪栏、时间轴还原到该时刻。
  3. 情绪栏（9 格）：涨停/跌停、触板/炸板、封板率、最高板、晋级 1→2 / 2→3 / 3→4+、
     冲板中（≥7%）、缺涨停价/封板未知。
  4. 左：主视图，面板标题处切换**题材梯队 / 今/昨对比**。
     **题材梯队矩阵**：列 = 题材（按涨停家数降序，列头含梯度与首家时间）；
     行 = 5 板…首板 + "炸板/冲板"行，行头"昨 N → 今 M"。卡片：首封时间（盘中带"≈"）、
     封单额、开板次数；一字板、回封、断板/炸板、冲板、ST、北交所（灰化+"无交易权限"）、
     封板未知各有样式；每格超量折叠为"展开 N 只"。盘后定版时差异以红字"≠ 直取值"标注。
     **今/昨对比**（参照同花顺涨停聚焦同名视图）：按"昨日 N 板 → 今日 N+1 板"自高到低
     分组，末组为"昨日首板 → 今日 2 板"；组头含今日家数与晋级率。左列为昨日 N 板全部个股
     及今日实时涨跌幅、所属题材；右列同行显示已晋级者的首封/封单/开板回封；已晋级排前，
     未晋级灰化并标炸板/断板/冲板中/跌停；首板组默认只显示已晋级与冲板中，其余折叠。
     第四列"AI 晋级（影子）"见 §5.5。昨日 N 板名单取直取 `limit_list_d`（ST 用
     `daily_flags`），今日涨跌幅 = 实时价 ÷ 昨收 − 1。
  5. 右：选中票分时（叠同题材前排、涨停价虚线、首封点、成交量）；题材涨停家数盘中累计
     曲线（前 4 题材）；封板时间轴（含"第 N 家"、开板、回封、改列事件）。
- 盘中前端每 15 秒轮询；非交易时段按 `/market` 现有的 `next_open_at` 退避方式。

### 5.4 三种状态的数据取用

| | 盘中实时 | 当日盘后定版 | 历史日期 |
|---|---|---|---|
| 触发 | 交易时段 | 当日 `limit_list_d` 入库后自动切换 | 选择过去交易日 |
| 连板/首封/开板/封单 | 盘中派生（"≈"） | 直取 `limit_list_d`；ST 用 `daily_flags`；盘中值对照 | 同定版 |
| 分时 | 15 秒留存 | 15 秒留存（可切 1 分钟线） | 有留存用留存；否则 QMT 1 分钟线，首根成交量显示缺失（D-23） |
| 回放 | — | 有 | 仅有留存的日子 |
| 题材归属 | 当日概念快照 | 当日概念快照 | 当日概念快照；**无快照的日子不分题材**，只显示高度梯队并说明原因 |

### 5.5 AI 晋级（影子）列

- 只读取 AI 涨停观察（影子榜单，`docs/reference/limit-up-shadow.md`）的结果，看板不做任何
  模型计算。影子模型在 T 日收盘后给出 T+1 收盘封板概率 `p_close_limit`；对今日封板的
  N 板票，它就是"明日晋级到 N+1 板"的概率。
- 盘中：左列每只昨日 N 板票显示**昨日对它的预测概率**与今日结果（✓ 晋级 / ✗ 未晋级 /
  进行中）。盘后定版与历史日期：显示今日晋级者的**明日晋级概率**。
- 视图顶部常驻"AI 影子 · 非交易信号"、模型版本、滚动 Precision@20，以及昨日预测对今日
  连板票的命中情况；任何票无预测（不在打分范围或未存储）显示"无预测"，不补值。
- **前置依赖（独立 Issue）**：影子榜单当前只保存 Top-20（`score_snapshot` 截断，
  `src/qsys/research/limit_up_shadow.py`）。须扩展为额外保存当日涨停股的全部打分，
  保持其只读、不可覆盖最终快照的既有约束；看板只读这份扩展结果。影子快照不可用、
  过期或失败时，该列整体显示状态而非数字。

### 5.6 颜色
- 本页按涨红跌绿：上涨/涨停/连板为红（`--bad` 色值），下跌/跌停为绿（`--ok` 色值），
  炸板/冲板/回封为橙（`--warn`）。
- 现状：系统全局 `.up` 为绿、`.down` 为红（`base.html`），与 A 股惯例相反。维护者要求
  全系统保持涨红跌绿；全局修正（含 `/market` 指数涨跌等所有使用处）作为**独立 Issue**，
  不夹带进本功能，但应在本看板上线前或同时完成，避免同站两种配色。

## 6. 设计者决定（可改）

- **进入看板的票**：当日任一时刻触板，或涨幅 ≥ 7%（冲板）；一经进入当日不移出。
- **留存范围**：盘中全市场快照先写当日临时文件，保证入选前的分时也完整；收盘后压缩为
  "入选票全日序列 + 每快照情绪聚合"。全量长期保存约每日 500 万行，按 #126 不值得。
  **临时全量文件例行删除（维护者 2026-11-11 授权）**：放数据盘 `/data/qsys` 下本组件专属
  目录，不放系统盘；压缩后校验（行数、入选票全日序列逐值相等、情绪聚合由全量重算一致）
  通过才删除当日全量；失败保留全量并告警。授权仅限本组件当日临时全量文件。
- **归列稳定性**：首次归列后不动，除非原概念涨停家数跌到新最高概念的一半以下才改列；
  改列写入时间轴。
- **历史日期的题材**：概念成分只有拉取当日的快照，不用当前成分回填过去；上线前的历史日
  只显示高度梯队，不分题材。
- **北交所**：计入情绪栏（全 A，AGENTS §3.4）；矩阵中灰化并标"无交易权限"，不计入题材家数。
- **ST**：照常纳入，标 ST（只认 `is_st`）。
- 留给实现者：存储格式（SQLite/Parquet）、表结构、前端实现（服务端 SVG 或轻量 JS，
  零外部依赖与现有页面一致）、采集为常驻服务还是 timer 驱动。

## 8. 分阶段（同一次上线交付）

1. **P0 探针**：概念接口与盘口字段（§4.2）。
