# 计划 07：运维组三页

**日期：** 2026-11-19
**Issue：** #662
**边界：** 只改长期需求分支 `feat/web-redesign`；不合入 `test/main`，不部署或重启节点。

## 事实边界

- 服务看板只读 `ServiceRun` 与 health-observer 的本地 SQLite，不在请求路径调用 `systemctl`、journal、Redis 或 Windows。
- 节点资源、链路、进程、QMT、安全核验、组件版本和三方发布证据只读专门采集器发布的 JSON 快照。
- 本计划定义并消费快照契约，不在 Web 进程中采集；生产采集器另开 Issue/分支并按组件流程发布。
- 快照缺失、过期、格式错误或为 symlink 时显示缺失，不回退现场探测，不补 0。
- 页面没有重启、停用、补跑、切换版本或回滚按钮。

## Review Focus

1. Web 请求路径不执行节点探测，也不读取 journal、白名单或部署记录。
2. 快照缺失或过期不会显示成正常或 0。
3. 系统盘与数据盘独立显示各自失败线；不从一个盘推断另一个盘。
4. 安全页不回显 key、地址、指纹或配置原文。
5. 历史失败不会被后来的成功覆盖；修复显示为“已修复”。
