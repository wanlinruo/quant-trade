   只记录返回码、长度及合成值精确匹配，不新增save，不输出值或账户标识。结果由#541记录。

   执行当前py36基线。未取得返回或出现空值/签名错误时保留原记录，不重试缺省参数。
4. 只读查看系统设置→模型设置的实际当前选项、py3.12可用性、官方下载信息和目标目录。

   已有审计回退副本。不复制整套userdata，不按逻辑大小估算释放量，不为下载自动清理文件。
