## 4. 恢复需要的事实

完整场景矩阵见[计算输入与恢复契约](../reference/qmt-inner-input-contract.md#状态恢复验收矩阵)。
这次只读查询没有完成其中任何一项完整恢复验收。

| 必需事实 | 当前缺口 | 继续推进条件 |
|---|---|---|
| 逐lot分支、入场价、取得日及FIFO核销 | 聚合持仓不提供等价账本；无非空样本 | 正式内部持久化，或可无歧义重建的完整回报与归属证据 |
| 发送前后崩溃的订单状态 | 当前ORDER空且完整性未知 | 可区分已发/未发/未知，未知不补发 |
| 稳定成交标识与跨运行去重 | 当前DEAL空，历史全局函数不可用 | 真实非空样本、标识范围/稳定性、覆盖与重复回报验证 |
| 部分成交、冻结与累计费用 | 未取得相关样本 | 逐回报数量与委托累计费用对照，不能重复计最低佣金 |
| 人工/他模型隔离 | 仅查询整账户，没有归属样本 | 正式策略名/备注/订单身份语义与历史保留确认 |
| 跨模型/客户端重启恢复 | ContextInfo自定义属性不跨模型重跑 | 券商正式状态机制及真实恢复验证，不能使用内存set证明持久化 |
| 首次空仓切换 | 当前查询空，柜台新鲜度/完整性未知 | 最新真实账户核对、活动委托与pending闭环、唯一交易所有者 |

旧适配器提交策略名qsys及client_order_id作为备注，分支tag不作为独立券商参数传入；
不能直接假设查询备注就恢复了tag。应实测实际格式/保留范围和历史覆盖，不拼接猜测映射。

## 6. 决策回调守卫准备（#537）

`docs/reference/qmt-inner-runtime-guard.py`提供独立Python3.6兼容准备件，不包含QMT入口、
取数、时钟读取、调度注册/注销、账户、持久化或交易API，也未接入生产消费者。
原计算核心和冻结策略保持不变。语法/离线测试通过不等于已在本券商沙箱验证threading等依赖。

调用方必须显式给出交易日、当前运行标识和每个Checkpoint的时刻、允许迟到、是否需要
报价及报价有效期，不提供生产默认值。所有datetime输入是已确认的UTC+8无时区对象，
守卫不转换未知时基、不按星期猜交易日、不读取本机时钟补齐缺失。quote_at仅校验时效；
报价内容、单位、市场范围与策略数据质检仍须由已验证的输入适配器承担。

RecoveryEvidence须绑定同一交易日和run_id、明确检查时刻与有效期，并逐项确认身份、
账户新鲜度、所需历史完整、lot恢复、订单对账、成交去重、单一所有者、停止控制、日历与
时钟。只有严格布尔True有效；None、False、数字1和字符串均不放行。证据记录本身
不是证明，实际run_id唯一性、证据生产及有效性须由未来验证过的原生适配器保证。
不得写死标识或手填True替代这些事实；#541目前的身份正对照不足以生成放行证据。

| 情况 | 准备件行为 | 仍需原生现场证明 |
|---|---|---|
| 证据缺失、过期、来自未来、其他运行或日期 | 不进入业务回调 | 持久状态/回溯、新鲜度与真实运行绑定 |
| 早到、超过显式迟到窗口、跨日 | 不进入业务回调 | 实际调度时刻与允许延迟政策 |
| 必需报价缺失、过期、来自未来或其他日期 | 不进入业务回调 | 原生报价时基、时效与质量 |
| 同一检查点重复 | 进入业务前先消费；已消费不重播 | 跨模型/进程/重启的去重与唯一所有者 |
| 回调抛错/中断，副作用结果未知 | 原样抛出，保留已消费状态，整个实例暂停 | 实际委托已发/未发/未知对账，不能盲目补发 |
| 同实例并发或重入 | 非阻塞互斥立即拒绝，不排队保存旧输入 | 实际运行入口、调度及系统控制 |

尚未进入回调的拒绝不消费检查点；调用方若再次尝试，须重新取得时刻、行情和证据，
仍受原截止点约束。回调进入后即使失败也不释放“已消费”状态；发生异常/中断后整个守卫实例暂停，
其他检查点和新的证据记录也不能解除暂停，没有本地reset入口。新实例须使用新的真实运行
标识并重新取得恢复证明；运行标识的唯一性与实际恢复仍归正式适配器，不能靠新建对象绕过。
局部互斥不提供共享锁；
内存集合不跨运行保存，新对象缺恢复证据仍拒绝。停止控制只是待验证的证据项，守卫
不会替代原生急停、停止任务或取消委托。DispatchResult.completed仅指回调正常返回，
不代表任何券商受理、成交或交易激活。原生委托结果未知时，正式适配器仍须阻断，
不能用正常返回或旧证据掩盖未决状态。

离线夹具覆盖早到/迟到边界、行情与证据时效、跨日/跨运行、各项未证实元数据、并发/重入、
回调异常/中断及未知副作用不重播。正向证据和时间窗口仅为合成测试，不输入QMT，
不作为生产允许延迟/报价过期阈值，也不证明真实恢复机制或市场日历已存在。
#537原生调度次数适配、注销、交易日现场与#541恢复验收均保持未完成。
