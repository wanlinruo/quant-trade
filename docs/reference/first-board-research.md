# AI 首板机会研究（Issue #230）

## 边界

本研究在 T 日收盘后从当日未封板的普通沪深 A 股中产生 T+1 首板候选。
`daily_flags.is_first_board` 是唯一收盘首板标签。模型输出不是交易授权；历史竞价
数据、真实成交和交易收益门禁未全部通过时，不生成 `strategies/` 文件。

固定切分为 TRAIN 2023-04-01～2024-12-31、VALID 2025-01-01～06-30、
TEST 2025-07-01～12-31、OBS 2026-01-01～09-30。特征组合只按 VALID
Precision@20 选择，进入 TEST 前冻结。

## 数据依赖

- `moneyflow_daily`：Tushare `moneyflow`，金额统一为元；每日完整截面替换写。
- `industry_membership`：申万三级行业历史区间；采集时显式分页合并
  `is_new=Y/N`（上游默认只返回 Y），并按 `in_date/out_date` as-of 连接。
- `auction_open_daily`：Tushare 历史竞价源的隔离表。当前账号没有
  `stk_auction_o` 权限，不能用于模型或晋级。
- `auction_ticks`：QMT 09:25 快照，仅用于重叠口径验证和未来实时门控。

资金流与行业成员关系先在目标环境做幂等回补。`--industry` 会执行全表原子覆盖；
`--moneyflow` 只替换交易日完整截面，因此中断后可以用相同日期安全重跑：

```bash
uv run python scripts/backfill_first_board_inputs.py \
  --warehouse /data/qsys-test/warehouse-current \
  --config config/deploy.local.toml \
  --start 2023-01-01 --end 2026-09-30 \
  --moneyflow --industry
```

首次回补先在测试仓库执行并核对日期覆盖、唯一键和金额单位；验证完成前不得直接把
相同命令指向生产仓库。

## 隔夜研究

模型比较 #210 重排、动量、固定启发式、Logistic，以及纯价量、资金流、行业扩散、
资金流与行业组合四种两阶段 LightGBM。两阶段概率为：

`P(T+1 首板) = P(T+1 触板) × P(T+1 首板 | 已触板)`。

运行入口：

```bash
uv run python scripts/research_first_board.py \
  --warehouse /data/qsys/warehouse \
  --legacy-ranking /data/qsys/research/issue-210/run-20261010/predictions.parquet \
  --out /data/qsys/research/issue-230/run-YYYYMMDD
```

产物包含数据指纹、全量预测、Top20、指标、月份、校准、冷启动/反包分层、特征重要性、
模型和 verdict。即使隔夜排序通过，竞价证据缺失时 verdict 仍固定
`promote_to_shadow=false`、`promote_to_trading=false`。

## 09:31 首分钟过滤替代路径（2026-10-11）

历史竞价既用于原设计的 Top20→0–3 只门控，也用于开盘附近的成交裁决；但冻结
隔夜模型本身不读取竞价数据。为避免在门控价值尚未得到证据前购买历史权限，先独立
裁决一个延迟入场变体：

1. 隔夜 Top20、胜出模型与 VALID/TEST/OBS 切分保持冻结；
2. 09:31 只使用此时已经可见的第一根连续竞价分钟线训练二次门控，每日留下 0–3 只；
3. 下单后只允许用严格后继、在 09:32 可见的分钟线判断成交；缺线直接拒单，禁止回退
   到日线开盘价；
4. 分钟身份以规范表 `visible_at` 为准，而非供应商 `ts`。付费源第一分钟可能标为
   09:30，QMT 标为 09:31，但两者均在 09:31 才完整可见；
5. 二次 Logistic 门控只在 VALID 前70%拟合，在 VALID 后30%从预先限定的
   80%/90%/95%分位阈值中选择一次，TEST/OBS 不参与模型或阈值选择；
6. 主裁决为下一交易日开盘退出、额外1.0%入场成本压力；同时检查0.5%/1.5%成本和
   11:25/14:25退出，并与隔夜 Rank Top1/Top3、无阈值 Gate Top3 对照。

运行入口：

```bash
uv run python scripts/research_first_board_first_minute.py \
  --warehouse /data/qsys/warehouse \
  --ranking /data/qsys/research/issue-230/run-20261011/predictions.parquet \
  --out /data/qsys/research/issue-230/first-minute-YYYYMMDD
```

研究专用执行适配器位于 `scripts/issue_230_first_minute_strategy.py`，刻意不放入
`strategies/`，不能从策略页导入。该路径即使历史门禁通过，也只允许另开冻结规则后的
前瞻只读影子观察；它不替代 #234 对原 09:25 竞价路径的历史同口径验证，也不直接授权
模拟或实盘。

### 生产裁决结果

2026-10-11 在生产数据上完成冻结研究，权威产物为
`/data/qsys/research/issue-230/first-minute-20261011-v2`，来源 SHA
`4eafc79d3ca1a08d0de4d1dec39e0dfcb6141af0`。manifest 中六个核心产物的 SHA256
均已独立复核一致，TEST/OBS 的买入成交时间也全部为 09:32，没有同分钟成交或缺失分钟
回退。

首分钟门控对“当天最终封首板”的质量过滤有效：冻结阈值策略在 TEST 命中
51/138（36.96%）、OBS 命中 127/475（26.74%）；隔夜 Rank Top3 对照分别只有
15.34% 和 12.71%。但过滤后的信号无法转化为可执行收益：下一交易日开盘退出时，
即使额外入场压力成本为 0，TEST/OBS 账户收益仍分别为 -9.17%/-20.92%；主裁决的
额外 1% 压力下分别为 -17.44%/-44.48%，Sharpe 为 -3.37/-4.93，裁决为
`TRADING_FAIL`。

成交归因进一步表明，09:31 决策后到 09:32 成交只增加约 0.28%/0.09% 的平均价格；
即使用不可真实成交、仅作诊断的 09:31 决策价代替，逐笔次日开盘毛收益均值仍为
-0.32%/-0.21%。真正大的价格变化发生在等待首分钟期间：开盘到 09:31 决策价平均已
上涨 0.83%/1.71%。用同一个首分钟门控事后假设开盘成交虽会得到正的逐笔毛收益，
但这包含未来信息，不能作为策略结果。

因此结论不是“竞价只用于估算滑点”，而是：原 09:25 竞价数据若继续研究，必须承担
在价格上冲前完成质量门控的核心信号职责。09:31 路径不晋级影子或交易，不发布
`strategies/` 文件；#234 恢复为下一研究优先级，但购买前仍需确认权限确实包含
`stk_auction_o` 全历史，并在回补后通过与 QMT 09:25 快照的同口径门禁。

### QMT 竞价小样本试验

2026-10-11 在不购买新数据的前提下，为冻结 OBS Top20 定向回补 QMT 竞价逐笔。请求
2026-09-01～10-08 共 440 个标的日，QMT 返回 41,963 条快照；只有 09-11～10-08
连续 14 个交易日达到每日 20/20 完整覆盖，因此仅使用这 280 个标的日。原生产
`auction_ticks` 仍只保存首板次日候选，本次原始数据隔离在
`/data/qsys/research/issue-230/auction-pilot-20261011/raw-qmt`，没有导入规范仓库。

探索协议以前 9 日拟合、后 5 日评估。09:25 最终快照门控 Top1 在 5 个评估日命中
2/5，隔夜 Rank Top1 为 0/5；其中一只因每槽 10% 买不起一手，实际成交 4 笔。使用
09:31 可见的第一根连续竞价分钟严格成交、次日 09:30 退出后，额外 0.5% 入场压力下
账户收益为 +0.32%，额外 1% 时为 +0.15%；但 Auction Top3 在 0.5% 压力下为
-1.54%。结果说明竞价信息可能只在极高选择性下有价值，不能支持每日买满三只。

本轮曾在检查评估结果后移除“竞价 VWAP 相对统一成交价”这一无经济含义、仅反映舍入误差
的特征，因此最终五日结果不是可用于显著性声明的全新未触碰样本。权威状态固定为
`PILOT_HYPOTHESIS_POSITIVE`：它只生成值得继续验证的假设，不构成历史支持，不解除
#230/#234 阻断，也不允许发布策略或进入影子/交易。下一步必须保持现有特征与 Top1 规则
不变，在新到货交易日做前瞻验证，或购买历史数据后重新建立从未参与迭代的冻结 TEST/OBS。

### QMT 09:30 分钟线扩大预实验

“QMT 约一年历史”指 1 分钟线，不是 09:15～09:25 原始 Tick；Tick 实测仍只有约
20 个交易日。QMT 的 09:30 分钟线是开盘集合竞价单独一根、OHLC 四价相等的最终撮合，
因此可用于验证“09:30 过滤、09:31 首分钟成交”，但不能还原 09:24 盘口或未匹配委托。

2026-10-11 定向回补冻结 Top20 在 2025-10-13～2026-10-08 的分钟线，共请求 4,800
个股票日，得到 4,793 个股票日、1,155,113 行、969 只股票；7 个无行情股票日对应的
整日 Top20 全部剔除。最终 240 个候选交易日中 233 日达到 20/20 完整覆盖。原始数据
隔离在 `/data/qsys/research/issue-230/opening-minute-pilot-20261011/raw-qmt-minute`，没有
导入或覆盖规范仓库。

扩大协议只用 09:30 最终撮合价、量、额与隔夜排名特征：前 155 日拟合
（2025-10-13～2026-06-08），后 78 日评估（2026-06-09～10-08）。评估期 Opening
Top1 首板命中 26/78（33.33%），显著高于原始 Rank Top1 的 14/78（17.95%）；但
实际 09:31 成交、次日开盘退出仍失败：3% 追价保护带下，零额外压力收益 -5.70%，
0.5% 压力收益 -9.93%，1% 为 -11.76%，1.5% 为 -14.71%。五个自然月收益全部为负，
0.5% 压力的日收益 bootstrap 区间上界也低于零。

命中率没有转化成收益的直接原因是可交易样本劣化：26 个最终首板中只有 18 个成交，
这些交易平均收益 +6.68%；另外 48 个未封首板的成交平均亏损 -4.13%，总亏损覆盖了
首板利润。把追价保护带由 3% 放宽到 5%/10% 也没有增加完成交易数，账户收益仍为
-9.27%/-9.30%，不能靠接受更高追价解决。Top3 在 0.5% 压力下更差，为 -30.86%。

权威产物为 `/data/qsys/research/issue-230/opening-minute-pilot-20261011/study-v2`，来源标签
`archive/issue-230-opening-minute-20261011-v2`；产物哈希已独立复核，所有主路径买入均为
09:31、卖出均为次日 09:30，无缺失分钟回退。裁决为
`EXPANDED_PREEXPERIMENT_NEGATIVE`：它推翻短样本对“09:30 最终撮合 Top1 可直接交易”
的乐观判断，但不等价于否定 09:24～09:25 原始盘口特征本身；后者若继续研究，仍需
历史竞价逐笔或长期前瞻自采。

#### 11:25 / 14:25 两阶段退出敏感性

同一冻结模型、同一 78 个评估交易日上，另测“每个持仓日 11:25 若相对昨收红盘且
未涨停则卖；否则 14:25 未涨停则卖；14:25 仍涨停则隔夜并在下一交易日重复”。红盘
严格按当日昨收而非买入成本判断，缺盘中价或涨停价时不做乐观替代；跌停卖单按真实
不可成交处理。

结果没有扭转结论。Opening Top1 在零额外压力下收益 -7.10%，比次日开盘退出的
-5.70% 更差；在 0.5% 压力下为 -9.87%，仅比 -9.93% 改善 0.07 个百分点，Sharpe
-2.59、最大回撤 13.22%，日收益 bootstrap 95% 区间为 [-0.283%，+0.042%]。1% 压力
下为 -12.36%。Top3 在 0.5% 压力下由 -30.86% 小幅改善至 -30.49%，但最大回撤由
30.86% 扩大到 34.22%。所有组区间末均无未平仓仓位。

Top1 的 63 笔闭合交易中，28 笔在 11:25 卖出、35 笔在 14:25 卖出；51 笔只持有
1 个交易日，12 笔延长至 2～4 个交易日。延长持有确实抓到 +22.15%、+19.89%、
+15.74% 等收益，但也出现 -23.50%、-22.95%、-13.04% 等损失；共有 12 次 14:25
卖单因跌停无法成交。Top3 甚至抓到一笔持有 5 个交易日、收益 +59.04% 的连板票，
总体仍然大幅亏损。这说明问题不是“次日过早退出”单一造成，而是错误入选与封板后
跌停流动性风险共同吞噬连板收益。

#### 结果导向的入选质量门禁

在不改变隔夜 `lightgbm_price` Top20 的前提下，新增第二层 09:30 质量门禁。它不再以
“是否最终首板”作为唯一优化目标，而是分别针对次日开盘退出和 11:25/14:25 两阶段
退出，学习 09:31 能否成交、扣费后收益、10% 下行分位数，以及两阶段退出的卖出受阻
风险。每天每套退出最多选一只，条件不足时允许空仓。固定主口径为每槽账户资金 10%、
3% 追价保护、0.5% 额外入场压力、普通滑点和完整 A 股费用。

233 个已有交易日全部被视为已触碰的开发数据。以前 100 日起步、其后 133 日扩展窗口
OOF 预测选择一次性阈值。次日开盘方案选出 56 日、闭合 55 笔，入选日平均账户贡献
+0.0152%，计入空仓日后累计收益 +0.75%、Sharpe 0.26、最大回撤 6.12%；两阶段方案
选出 51 日、闭合 48 笔，入选日平均账户贡献 +0.0390%，计入空仓日后累计收益
+1.71%、Sharpe 0.36、最大回撤 4.75%。两套方案经双重比较校正后的日收益置信下界
都低于 0。它们只是很弱的开发期正向信号：样本少、阈值已在这些 OOF 结果上选择，
且首板命中率并不高，不能据此宣称可交易或支持购买历史竞价数据。

候选级仿真已与旧 Top1 标准回测逐笔对账：共同成交记录的买价、卖价和卖出日完全
一致。新标签器按每只候选独立固定槽位计算，因此不受旧组合并发持仓和现金竞争影响；
最终向前裁决仍使用账户 10% 仓位日收益，并要求无缺失回退、期末无未平仓。
