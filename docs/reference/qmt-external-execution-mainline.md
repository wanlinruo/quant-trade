# 江海大QMT外部决策薄执行器唯一主线

日期：2026-11-05。实现总跟踪：[#601](https://github.com/wanlinruo/quant-trade/issues/601)。

## 裁决与背景

江海新版大QMT取消独立交易入口，维护者已向券商确认当前通道不再支持外部`xtquant`，只能由
QMT内置策略使用正式交易接口。仓库中的`XtQuantAdapter`、`run_agent.py`和旧MiniQMT任务因此
只是历史资产，不是当前账户的可用执行入口。不得因模块仍能导入、旧代码仍存在或其他券商支持
`xtquant`，推定本账户可以直接连接。

本项目唯一实施路线固定为：

```text
Linux：真值数据、策略计算、风控、业务账本
    → 持久交易意图
Windows：专用执行网关、身份认证、发送账本、unknown对账
    → 获准并验证的本机IPC
大QMT：内置薄执行器
    → passorder / 撤单 / 原生委托与成交查询和回调
江海券商柜台
```

不再推进完整策略、动态行情、历史数据、指标和业务账本迁入QMT。QMT内只保留无法移出的最小
交易边界。编辑器只用于首次安装、源码核验、编译及配置正式策略运行；策略计算不在编辑器完成，
生产运行不得依赖RDP、界面自动点击或编辑器模拟模式。

## 组件职责

### Linux核心

- 继续使用既有真实数据源、冻结参数和策略实现，生成标准化订单意图。
- 在发布意图前完成账户姿态、行情时效、仓位、额度、北交所禁开仓和KILL等风控。
- 持久保存策略lot、pending和资金/数量预留；Windows ACK不释放这些状态。
- 消费真实委托、成交、拒单和撤单事实，完成业务账本与券商事实对账。

### Windows执行网关

- 是Linux与QMT内置执行器之间的唯一桥接进程，不直接调用`XtQuantTrader`下单。
- 先持久化发送事实，再投递；绑定意图ID、内容SHA、attempt、nonce、会话、期限和生产身份。
- 只向当前QMT会话发布完整且通过认证的消息；冲突、错签、乱序、过期和未知字段全部拒绝。
- 接收QMT侧传输ACK和原生回报。超时或进程退出进入`unknown`，先查询对账，绝不自动重发。

### QMT内置薄执行器

- 不获取外部行情、指标、候选池或策略状态，不进行选股和仓位决策。
- 只验证消息身份、完整性、时效、顺序和允许的订单字段，再调用正式内置交易API。
- 传输ACK仅表示意图已被接收/持久处理，不表示券商受理；不得伪造券商订单号或成交。
- 通过QMT原生委托、成交、拒绝、撤单查询/回调输出真实事实，并保留稳定关联标识。
- 重建、重复回调、客户端重启或Windows重启时不得重复执行已处理或状态不明的意图。

## 事实状态机

```text
created → persisted → sent → transport_received
                            ↘ unknown → broker query/reconciliation
transport_received → broker_accepted → partial/fill
                                  ↘ rejected/cancelled
```

任何阶段都不得把后一级事实提前写入：`transport_received`不是`broker_accepted`，`passorder`调用
返回也不是成交。没有可靠券商单号时保持空值，并用意图ID、QMT回报字段和后续查询完成关联。

## 分阶段验收顺序

1. **完整合成意图、零交易验证（已完成）**：在当前QMT中运行固定合成消息，逐字段校验并返回
   `executed=false`、`authorizes_trading=false`；不含账户、市场数据或真实委托。
2. **正式运行模式与许可**：确认IPC在正式策略模式中可用，并取得券商对“外部意图进入内置
   薄执行策略”的明确许可；编辑器模拟结果不能替代这一层。
3. **无人值守运行**：配置正式策略启动，分别验证接收模型重建、QMT客户端重启和Windows重启；
   全过程无需打开RDP，失败保持停止交易姿态。
4. **只读账户与回报**：在明确授权后验证账户身份、委托/成交查询和回调字段，不发送委托，
   建立真实唯一标识和状态映射。
5. **隔离故障组合**：验证丢ACK、回报延迟、进程退出、重复/冲突消息和`unknown`查询对账；
   保持pending与预留，不把传输失败伪造成券商拒单。
6. **最小真实闭环**：仅在维护者对具体窗口、账户、证券、方向和数量再次明确授权后，执行最小
   委托/撤单/回报闭环。此步骤不由“继续推进”自动授权。
7. **生产激活**：完成单一交易所有者、KILL、监控告警、回滚/停止和发布证据后，另按#137审批。
