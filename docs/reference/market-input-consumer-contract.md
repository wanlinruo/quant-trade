# 全市场行情覆盖与消费范围（#588）

[order-market-access.md](order-market-access.md)。维护者明确的观察池是全A含北交所，交易
候选池保持现有沪深范围并排除北交所/科创，不能为了消除分钟告警改变市场情绪口径。

不是运行时全量质量通过证明。

## 网关覆盖与兼容

新生产者保留本次请求的完整证券集合，并将集合SHA、来源及明确会话绑定到同一原子概览。
沪深京分别列请求、收到、有效、缺失、无效、异日、返回停用标记和源时间首尾；原生
低流动性股票当天较早的源时间保留，不用固定45秒无成交猜测丢数。返回停用标记不作为
已证实停牌事实，该项仍要求复核。覆盖完整仅代表本次请求集合已观察，价格/数量/源范围
正确性仍独立验收，不能据集合SHA代替数据正确性。

盘前限价键有明确当日时才绑定其会话；QMT板块集合无日期证据时保持会话null及unknown，
不拿请求时的日期反填。900/200已知B股身份按现有全A定义明确排除并计数，未知身份另报。
实际返回不能反推请求集合，缺北交所不通过缩分母隐藏；新绑定路径仅统计本会话有效报价，
异常/缺失继续展示并保留原事实。新字段缺失的旧快照coverage保持null。

本次没有有效股票报价（包括空响应、全部失效或只有指数）时，概览明确拒绝发布，
保留上一份原字节及发布时间，由实际Web读取器按原时效显示过期；不生成全零市场统计。

原生时间、价格、量额关键字段缺失时，新网关不再填当前时间、0或另一个价格来生成该条
报价，覆盖中表现为缺失；0原值继续保留，非整数原生量不再截断成整数。已有跨机tick数量契约保持，本次没有改变其单位
或以换算解决#586。旧消费者可忽略新增coverage，新Web兼容旧快照但明确显示待核验。
正常发布仍须先升级读取器再升级生产者，新旧组合和Windows门禁单独验收；未启动QMT或
交易服务进行验收。

## 消费输入的独立核对

`qsys.data.quality.consumer_inputs`接受显式消费清单及证据，精确核对数据集、字段、频率、
观察/交易/归档范围、证券集合、日期区间、当前输入版本及证据时效。空合同、缺证据、重复
候选证据、缺版本、版本变化、范围不足和必需warning/failed/unknown都不判为就绪。
不需要的归档failed单独保留在outside_contract，observed_quality_failed仍为true；不同
规则不投票、相互覆盖或重写历史。无效清单仅输出稳定错误类型，不回显输入或私有配置。

该模块是离线只读核对器：当前版本真实性与完整消费合同仍须由实际读取器/证据生产者
提供。不能用自编清单代替生产证据，旧QA缺少的细分范围/版本不反填，缺证据继续待核验。
结果authorizes_trading始终false，不接入自动交易放行、不替换当前全量service-checks门禁，
不改变冻结Gate的UNKNOWN_ALLOW。实际运行就绪接线及自然证据由#588继续跟踪，不能因
离线正反例通过关闭整个Issue。

调用（只读本地清单，退出码1表示必需输入未就绪，2表示清单无效）：

```bash
python -B -m qsys.data.quality.consumer_inputs <reviewed-manifest.json>
```
