# 生态闸门（S7 Gate）研究（2026-09-25）

脚本：`scripts/gate_study.py`（只读）与 `run_structural_backtest.py --no-gate`。
本文数字来自 2026-09-24 夜间在生产仓库的一次运行，区间 2026-01-01..09-22，
入场口径为推荐口径（09:25:10 决策、保护价 +3%、定量价 +0.5%、连续竞价判定）。

## 1. 问题

S6 分类 + S7 闸门每天都在拒单，但从没量过它值不值：拒掉的那些如果买了，是赚还是亏？

## 2. 方法

| 测法 | 做什么 | 优点 / 局限 |
|---|---|---|
| A 完整回测对照 | 同一区间跑两遍：开闸门 / `--no-gate` | 反映真实资金路径；一笔之差会改变之后所有仓位，样本小时噪声大 |
| B 逐笔反事实 | 对 `gate_decisions.csv` 里**每一条**判定，单独模拟一笔交易：入场价取当日开盘价，退出照搬策略的检查点规则（11:25 高开 `legacy_exit`、低开 `low_1125`；14:25 低开无条件；14:50 高开再判一次），T+1 起判，20 个交易日未走按当时收盘价平掉 | 互不影响，放行组与被拒组直接可比；不含成本与资金约束 |

拿不到分钟价的时刻跳过，不用日线冒充；整笔拿不到价记为无法评估（本次 0 笔）。

## 3. 结果

### 3.1 完整回测对照

| 指标 | 开闸门 | 关闸门 |
|---|---:|---:|
| 总收益 | **121.5%** | 106.8% |
| 年化 | 201.7% | 174.2% |
| 最大回撤 | **17.7%** | 20.4% |
| 夏普 | **2.19** | 1.86 |
| 平仓笔数 | 72 | 130 |
| 胜率（按 lot） | **75.0%** | 60.8% |
| 单笔平均收益 | **4.02%** | 2.14% |

闸门把交易笔数砍掉约 45%，收益更高、回撤更小、胜率高 14 个百分点。

### 3.2 逐笔反事实（183 条判定，全部可定价）

| 组 | 笔数 | 平均收益 | 中位数 | 胜率 | 合计 |
|---|---:|---:|---:|---:|---:|
| 闸门放行 | 92 | **+4.79%** | +3.02% | 75.0% | +440.9% |
| 闸门拒绝 | 91 | **−0.61%** | 0.00% | 51.6% | −55.8% |

**被拒的那批整体是亏的**，放行的那批平均每笔多赚 5.4 个百分点。

按分支：

| 分支 | 放行笔数 / 平均 / 胜率 | 拒绝笔数 / 平均 / 胜率 |
|---|---|---|
| LOW_MAIN | 31 / **+5.47%** / 83.9% | 30 / −0.54% / 40.0% |
| HIGH_MAIN | 38 / **+3.44%** / 65.8% | 46 / −0.29% / 56.5% |
| HIGH_CHINEXT | 8 / **+1.94%** / 75.0% | 15 / −1.77% / 60.0% |
| LOW_CHINEXT | 15 / +8.33% / 80.0% | —（该分支不设闸门） |

按拒绝原因：

| S6 状态 | 笔数 | 平均收益 | 中位数 | 胜率 |
|---|---:|---:|---:|---:|
| RISK（低开主板：市场不弱且高热，或个股涨多贴近高点） | 30 | −0.54% | −1.10% | 40.0% |
| OTHER（高开两支：宽度或活跃度不足） | 61 | −0.65% | +0.20% | 57.4% |

两类拒绝都站得住：RISK 拒得最干脆（胜率仅 40%、中位数为负）；OTHER 的中位数微正、
平均为负，说明它拒掉的是"零星大亏拉低整体"的一批。

## 4. 结论

1. **闸门有效，保持启用。** 两种测法结论一致：被它拒掉的交易整体不赚钱（平均 −0.61%），
   而放行的平均 +4.79%。
2. **低开主板的闸门最值钱**：拒绝组胜率只有 40%，放行组 83.9%。
3. **高开创业板样本最少**（放行 8 笔），结论最不稳，暂不据此调参数。
4. **暂不调阈值**：目前只有 183 条判定、9 个月样本。建议随竞价研究一起按月复跑，
   样本到 400 条以上再做阈值敏感性分析。

## 5. 局限

- 逐笔反事实不含费用、滑点与资金约束，只比较价格上的相对优劣；完整回测对照才含成本。
- 20 个交易日的持有上限是人为设定；实际策略没有这个上限，长尾持仓的收益被截断。
- 本文样本只有 2026 年 9 个月、183 条判定；高开创业板仅 23 条（最新复跑的样本量见 4.2）。
- 闸门用的生态因子取自 T-1，本研究沿用同一口径，未检验因子本身的稳健性。

## 6. 研究期间修掉的两个缺陷

1. **判定留痕一直是空的**：`StructuralSelection` 每次选股都重置判定列表，而落盘产物在跑完
   后才读它——`gate_decisions.csv` 因此只有最后一个交易日（线上历次回测都是 0–1 行），
   回测详情页的"候选与 Gate"标签页一直没有内容。改为累计整段判定后，本次两组各 183 条。
2. **上报字段漏转发**：`Context.report` 没有跟着加 `routed` 参数，策略每次竞价调用都会抛
   `TypeError`，会让 2026-09-28 的模拟盘与影子盘竞价事件失败。已修复并补了"真实上下文 +
   签名一致"两条测试。
