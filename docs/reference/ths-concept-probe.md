# 同花顺概念接口探针（#648 P0）

探针：`scripts/probe_ths_concepts.py`；证据：`artifacts/ths_concept_probe_20261112.json`
（2026-11-12 实测，只含概念代码/名称/计数与抽样摘要，不含成分全量明细与凭证）。

## 结论

1. **当前积分可调用** `ths_index`（`exchange=A, type=N`）与 `ths_member`，单次全量返回，
   `has_more=false`。
2. `ths_index` 概念类共 **395** 个，列为 `ts_code, name, count, exchange, list_date, type`，
   `count` 无空值。成分数分布：≤50 有 109 个，51–100 有 106 个，101–300 有 123 个，
   **>300 有 57 个**，最大为 3844（融资融券）。
3. `ths_member` 只返回 **`ts_code, con_code, con_name` 三列**，**没有生效/剔除日期和权重**。
   因此只能拿到"拉取当时"的成分，无法按历史日期还原成分。打板看板只能从上线日起，
   每个交易日盘前保存当日快照；上线前的历史日不分题材（设计文档 §6 已按此处理）。
4. `ths_index.count` 与 `ths_member` 实际行数**不总是一致**：融资融券 count=3844，
   实际返回 3903 行；煤炭概念 90/90、赛马概念 4/4 一致。归列时的"成分数"应以当日
   实际拉到的成分行数为准，并同时记录 `count`，两者不一致时标注出来，不互相替代。
5. 按股票反查（`con_code`）返回的是该股所属的**全部同花顺指数**，包括行业、地域等
   非概念类。抽样 000001.SZ 共 57 个，其中概念类 6 个；600519.SH 共 73 个，概念类 12 个；
   300750.SZ 共 87 个，概念类 19 个。使用时必须按 `ths_index(type=N)` 的代码集合过滤。

## 对设计的影响（需维护者确认）

成分 >300 的 57 个概念里，除了融资融券、深股通、沪股通、国企改革这类明显的泛概念，
**也包括常见的打板主线题材**：机器人概念（1216）、人工智能（1082）、新能源汽车（1061）、
华为概念（1002）、芯片概念（910）、储能（894）等，以及接近阈值的小米概念（373）、
核电（350）、信创（302）。如果严格执行">300 不参与"，这些题材的涨停票都不会归到
它们自己的列，而会落到更小的子概念或"其他"列。是否调整规则，由维护者决定，
记录在 #648。
