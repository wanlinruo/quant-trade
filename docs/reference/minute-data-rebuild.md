## 一、起因

D-19 回测对比（同一只读快照，2025-09-11 ~ 2026-09-15，结构策略，10 万）：

| 代码 | 累计收益 | 成交 | `no_quote` |
|---|---:|---:|---:|
| D-11 之前 `2528d65`（不含 ST 首板） | +102.3% | 164 | 21 |
| D-11 之后 `5b3077d` / `2f7aefa` | −76.4% | 82 | 468 |

主因 300344.SZ（*ST立方）：2026-01-28 以 1.33 买入，02-11 收盘 2.92（浮盈约 +120%），持仓期
**分钟线为 0**，11:25 / 14:25 / 14:50 检查点全部取不到报价、无法止盈；03-31 进入退市整理期
（立方退）后跌至 0.25，最终占净值 91%。

分钟线其实一直在采，但**按清单采**：`minute_bars`（QMT）每天约 150~190 只，是 D-11 之前
回测的候选日与持仓期；ST 首板当时不进候选池，其持仓期从未进入清单。

### 2.1 付费与 QMT 分钟线逐键比对（2026-09-15，两边都有的 45 只）

| 项 | 结论 |
|---|---|
| 条数 | 两边每只 241 根，09:30 ~ 15:00，无 13:00 |
| 全日成交量 | 45 只**全部一致**（付费股 / 100 = QMT 手） |
| 09:30 根 | QMT 只含集合竞价（例 000572.SZ 四价 4.44、73,743 手）；付费**合并竞价与开盘后一段成交**（4.44/4.54/4.43/4.50、93,485 手） |
| 同标签收盘价 | 仅 71.3% 一致；整体前移或后移一分钟反而降到 29% |
| 累计成交量 | 付费在 70.4% 的分钟上略多于 QMT，中位只多全日量的 0.001%~0.01%（约几秒成交）；09:30 多 0.48% |

判定：两边都是**收盘时刻标注**，付费边界比 QMT 晚几秒（推测按 3 秒快照聚合）。不存在
「整分钟起点标注」的一分钟前视，但付费 bar 可能包含标签时刻之后几秒的成交。

### 2.2 竞价量

策略的竞价量（`check_high_open` 比值 ≥ 0.03、`LOW_MAIN` ≥ 0.02）= 9:25 集合竞价撮合量。
实测 `auction_ticks` 撮合后首笔累计成交量与 QMT 09:30 分钟根成交量 **1,182 / 1,182 一致**。
付费 09:30 根合并了开盘成交，拆不出竞价量。Tushare `stk_auction` 无权限，**不需要购买**。

### 2.3 候选日缺口

D-11 口径下 2025-09-10 ~ 2026-09-16 首板次日 15,578 个，QMT 分钟线缺 **228** 个（ST 169）。
按月：2025-09 25、10 23、11 22、12 27、2026-01 29、02 14、03 21、04 21、05 1、06 13、07 4、08 2、09 26。

## 三、方案（用户 2026-09-17 确认）

1. 分钟线按交易日分区，避免每日整年重写（全市场一年约 3.2 亿行）。
2. 查询层按日期选源并统一契约：
   - 付费覆盖区间（≤ 2026-09-16）读付费，之后读 QMT；
   - **竞价量只取 QMT 09:30 根或 `auction_ticks`**，永不读付费；
   - 付费区间的检查点报价按保守口径：只用标签不晚于「检查点前一分钟」的 bar（最多滞后约 1 分钟，
     绝不包含检查点之后的成交）。**待用户最终确认。**
3. QMT 补采 228 个候选日（有时效，窗口约 242 个交易日）。
4. 网盘回补 2026 年全市场（一次性历史回补，非长期方案）。
5. QMT 每日全市场分钟线采集（长期方案），上线前收盘后实测吞吐。
6. 重跑 D-11 口径回测。

### 核查：缺陷来自卖家源文件，不是入库环节（用户要求，2026-09-17）

绕过入库代码，用 DuckDB 以全字符串直接读网盘原始 CSV，与暂存逐只对比
（脚本 `/home/ubuntu/scratch/raw_check.py`）：

| 交易日 | 原始 CSV 每只根数分布 | 暂存分布 | 暂存少于原始 |
|---|---|---|---|
| 2026-05-15 | 241:4,043 / 240:953 / 239:152 / 238:27 / 237:3 | 241:4,025 / 240:953 / 239:152 / 238:27 / 237:3 | 18 只 4,338 行（停牌占位行，OHLC 为空或 0，按规则隔离） |
| 2026-01-21 | 241:4,030 / 240:889 / 239:155 / 238:23 / 237:3 | 完全相同 | 0 |

- 600592.SH 2026-05-15 原始文件就只有 240 行，13:12 之后直接是 13:14。
- 原始文件自带非标准时间标签 13:00：05-15 有 98 行、01-21 有 90 行。
- 成交量：000547.SZ 原始 CSV 加总 = 暂存加总，均与 Tushare 日线不同——
  01-21 原始 191,432,300 股（整百）vs 日线 191,432,272 股；01-05 原始 524,559,732 vs 日线 524,559,733。
  卖家 2026 分钟成交量存在按手取整或舍入。

结论：入库如实保留源值，唯一的改动是按既定规则隔离停牌占位行。缺根、13:00 标签、成交量舍入均为
卖家 2026 年分钟文件本身的特征；同一卖家 2025 年批次（年度 ZIP）无此问题（非 241 根股-日为 0）。
