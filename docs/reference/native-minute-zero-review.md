## 接口与结论边界

[迅投正式接口说明](https://dict.thinktrader.net/nativeApi/xtdata.html)将`get_local_data`
描述为从本地文件读取，并列出`fill_data`控制空缺填充。该参数不能单独证明缓存中所有行
都对应有成交，也不能反向证明原生零量是伪造；实际容器按现场验证，不能按文档猜默认结构。
文档中tick结构化数组与本次空DataFrame均由显式类型校验处理，未知类型/缺列拒绝，不造字段。

历史RPC区间查询填充已有D-23/#114独立处置证据，但`source=qmt`无法区分读取API与当次契约。
本次确认的是：原生False返回包含这些零量，并与当前仓库相等。
**尚未证明**：所有原生零量都是真实无成交、所有旧规则都是误报，或可安全删除/豁免这些行。
不得用本轮同源一致替代独立市场验真，也不把D-23历史裁决自动扩展到新样本。
