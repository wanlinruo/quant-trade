# D-20 付费分钟线跨源差异归因

更新日期：2026-10-06  
生产证据：`artifacts/paid-minute-d20-attribution-20261006.json`  
复现工具：`scripts/analyze_paid_minute_d20.py`

## 结论

2020—2025 年付费分钟事实保持只读，不做跨源覆写。原年度报告中的差异不是一种问题：

1. 771,404 个 OHLC 差异股日中，付费日线与独立 Tushare 日线全部一致；差异位于
   付费分钟源的开高低收边界。没有证据允许用日线反推或改写分钟事实，继续作为 D-20
   源口径警告。
2. 25,312 个成交量差异股日中，13,846 个只差不超过一手，属于两个按手记录的日线源
   与整数股分钟汇总间的取整边界；98 个为小残差；11,368 个为重大残差。
3. 11,368 个重大成交量残差中 11,365 个、11,585 个成交额残差中 11,472 个位于
   北交所。两个相互独立的日线源一致，而分钟汇总不同，确认为付费分钟源差异；保留
   显式警告，不猜测填充。
4. 北交所 15:01—15:30 记录与异常高度相关，但把这些记录求和、取末条或取最大值，
   在有盘后记录的 1,828 个目标日中均不能同时还原日线量额。因此不能把“盘后记录”
   写成已证实根因，也不能据此删除或重算。
5. 2025 年 QMT 重叠区间的逐分钟差异主要是分钟切片边界，不是整日数值失真。聚合到
   11,848 个标的日后，成交量 11,848/11,848 在一手内一致，OHLC 11,767/11,848
   一致，成交额 11,683/11,848 在 100 元内一致。
6. 上述剩余 81 个 OHLC 日中，80 个是 QMT 已知的“有成交量但价格或成交额为零”坏日；
   唯一付费侧价格残差是 `603813.SH` 2025-12-24：付费分钟开盘 39.38，QMT 与
   Tushare 日线开盘均为 39.05，其余 HLC、量、额一致。该日保持显式源差异，不改写。

这组结论只解除“把大量逐分钟不相等误判为整源不可用”的疑问，不表示不同提供方的每根
分钟必须相等，也不授权静默切换任何消费者。

## 方法与边界

- 年度分析只读已发布的 `daily_discrepancies.parquet`、`daily_aggregate.parquet` 和
  Tushare 日线，不重复扫描 16.9 亿根分钟线。
- 只有北交所盘后编码验证会按目标标的日读取付费分钟分片；只有 2025 重叠验证会读取
  QMT 年度分钟文件。
- Tushare 是与付费日线独立的第二日线来源；它不能证明每根分钟的唯一真值，但能区分
  “日线错误”和“分钟聚合口径不同”。
- 2020—2024 没有等价的独立全量分钟源，不能把 2025 的逐分钟边界规律机械外推到每个
  历史标的日；这些差异继续留在质量页面，而不是被白名单隐藏。
