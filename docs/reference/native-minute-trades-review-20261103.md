## 修复同步警告的可诊断性

旧同步只显示“10条阻断结果”，容易混淆字段数、规则数和标的日数。本轮候选让同一实际
增量批次的ServiceRun记录字段结果数、不同blocking规则、每条规则的原始违规数/检查数、
样本路径和批次ID。多字段映射的计数只列一次，不按10字段把12案例相乘；不同规则计数
不求和冒充独立问题总数，不同责任范围保留不同计数组合，null不补0。

这里只改善新运行记录的说明，保留全部质量规则、blocking结果、同步warning和同步完成的
exit0契约；不改历史或市场值。候选合入、生产安装和自然验收分别记录，尚不能称警告根因
已修复或生产已经转绿。后续继续取证北交所和#586的量差。
