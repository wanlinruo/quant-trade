维护者本轮全权授权继续推进后，先核对现有磁盘和旧代理状态。C与E是两个独立100GiB

原审计根内没有剩余的大块未压缩队列候选，本轮复用此前旧静态队列的备份/压缩流程。

精确选择16个旧客户端`userdata_mini/down_queue_<数字>`文件，共1207964032字节。

压缩，保留其路径和文件身份，不删除C原件或回退副本。
