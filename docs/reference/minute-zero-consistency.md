本次一致性条件：前导行零量/零额/四价一致/正价格/等于直取参考价；时间键不重复；
首个正量分钟open与直取当日open一致。缺参考、null/非有限值、负量、零量正额、不平价、
参考价或首成交价不一致仍blocking。有日线成交而分钟全天无正量同样失败。
前导行不会被删除、补齐或重写；原B2规则ID与blocking严重度保留，旧红项不修改。
